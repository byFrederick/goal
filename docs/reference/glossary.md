# Glossary

The words Goal's code, API and UI use, one sentence each, with the place in the repository where each one lives. Where a term is planned but not built, the entry says so.

| Term | What it means | Where it lives |
| --- | --- | --- |
| Actor | Who did something (a user, an API key, an agent or a job), stored as `Actor.Ref()` such as `user:<id>` or `agent:<name>`. | `internal/core/domain/org.go` (`Actor`) |
| Agent | A model with its prompt, skills and connections that works at an agent station. | `internal/core/domain/line.go` (`AgentSpec`); `agents/*.md` in a definition |
| Andon | A stop of a factory's whole line, pulled by a person and open until someone clears it; while it is open the engine releases and claims nothing there. | `internal/core/domain/attention.go` (`AndonPull`), `internal/core/domain/andon.go` |
| API key | An organization's service account, acting with its scopes and at most its role ceiling on the factories it reaches. | `internal/core/domain/apikey.go` (`APIKey`) |
| Ask first | A connection tool's mode (`ask`, one of `allow`, `ask` and `off`) that stops an agent's call to the tool until a person approves or denies it as a tool approval; planned, not built yet. | `domain.ConnectionToolMode` (planned); [ADR 0031](../adr/0031-tool-calls-ask-first-and-standing-rules.md) |
| Assembly | An item split into parts that are worked as separate items and ship together. | `internal/core/domain/item.go` (`Assembly`, `StateAssembly`), `internal/core/domain/part.go`; [ADR 0012](../adr/0012-assemblies-and-parts.md) |
| Attention | What a factory needs from people right now, as the counts behind the app's badges. | `internal/core/domain/attention.go` (`Attention`) |
| Bake-off | A planned Jonah comparison of agent configurations (model, harness) on the same eval cases, by pass rate against cost; it is not built yet. | [MASTER.md](../design/MASTER.md) ("Vocabulary") |
| Board | The UI screen that shows a factory's items in columns by station. | `apps/web/src/features/board`, `apps/web/src/app/screens.ts` |
| Box | The disposable container one run works in, started through the `Sandboxes` port. | `internal/core/ports/sandboxes.go`; `apps/worker` (the image) |
| Bridge | The explanation of the gap between a factory's actual lead time and its target, largest step first. | `internal/core/domain/bridge.go` (`Bridge`) |
| Budget | A factory's weekly spending limit and what the engine does once it is used up. | `internal/core/domain/budget.go` (`BudgetPolicy`, `BudgetStatus`) |
| Class of service | The pull order of an item: expedite items are pulled before any standard item. | `internal/core/domain/item.go` (`ClassOfService`) |
| Connection | An organization's sign-in to an outside system, with write-only secret fields, that the runs of the factories naming it may use. | `internal/core/domain/connection.go` (`Connection`); `internal/adapters/store/postgres` |
| Connection kind | A template for connections: the fields an admin fills in, which are secret, and what a run's box gets from them. | `internal/core/domain/connection.go` (`ConnectionKind`), `internal/connkind`; `contracts/definitions/` |
| Constraint | The agent station that limits how fast a factory's line can deliver, measured over a window. | `internal/core/domain/constraint.go` (`Candidate`) |
| Contract | A file that two parts of the system agree on, such as the API, the permissions, the sandbox protocol, the environment registry or the definition schemas. | `contracts/` |
| Credential | An organization's stored secret, sealed and never shown again. A connection's secret field refers to one when its whole value is `{{name}}`: the reference is stored in the clear and the credential cannot be deleted while a connection refers to it. The listed agents of the factories it allows receive it as an env variable. Runs do not open credentials yet. | `internal/core/domain` (`Credential`, `ConnectionSecrets`), `ports.Credentials`; [ADR 0017](../adr/0017-credentials.md) |
| Definition | A factory's files (`factory.yaml`, agents, rules, skills, evals), stored as content-addressed blobs in the bucket. | `internal/core/domain/definition.go` (`Manifest`), `internal/config`, `internal/definitions`; [factory-definition.md](../engineering/factory-definition.md) |
| Delivery | One request a webhook endpoint received, kept 30 days with its headers, body and outcome: refused with a reason, accepted with no trigger matched, or created an item; decided, not built yet. | PostgreSQL (planned); [ADR 0026](../adr/0026-intake-triggers.md) |
| Denied commands | The Claude Code Bash permission patterns, such as `Bash(terraform apply:*)`, that an organization policy forbids every agent to run, added to each run's deny rules; planned, not built yet. | `internal/core/domain` (planned); [ADR 0024](../adr/0024-organization-policy.md) |
| Digest | The daily message sent at 08:00 in each person's time zone, by email and Slack as they choose, with what Needs you lists and the items done, andons and spend since the last one, across their organizations; at most one per person per local date; planned, not built yet. | `internal/core/domain` (the digest's contents), the digest job in goald; [ADR 0023](../adr/0023-notifications-and-sign-up-by-domain.md) |
| Draft request | A request, from the Definition screen's Ask bar or an agent's Ask Jonah for a fix, that an agent in a box with no repository changes a factory's definition files and goald writes the result into the draft, never publishing it; planned, not built yet. | `internal/core/domain` (planned); [ADR 0021](../adr/0021-asked-definition-changes-draft-requests.md) |
| Drum-buffer-rope | A release policy that lets work in at the pace of the constraint; the policy can be chosen, but its enforcement is not built yet. | `internal/core/domain/policy.go` (`ReleaseDBR`) |
| Edge, need | A stored dependency between two items: an item needs another item before it can be pulled. | `internal/core/domain/edge.go` (`Edge`, `OpenNeed`) |
| Eval case | A Jonah definition file, `evals/cases/<name>.yaml` (kind `EvalCase`): an input an agent must get right, the number of tries and one check (the agent's contract, a judge or a reference patch); every publish will run the cases on the draft, and a failing case will block it. The format and its checks are built, and so is `internal/jonah`'s eval loop: it runs each try as a task of kind `eval` (the model connection only, no connection in its token), grades it by the case's check (the contract, a judge's pass mark, or a reference patch's files and the checks) and records pass, fail or error (an infrastructure failure after one retry, or a cancel). A case passes when every try passes. No adapter runs a try in a box and goald does not run the loop yet. The Evals page of Jonah (`apps/web/src/features/jonah/evals-page.tsx`, `/o/$org/f/$factory/jonah/evals`) lists the cases with their last tries and runs one or all of them. | [factory-definition.md](../engineering/factory-definition.md#judges-and-eval-cases), `contracts/definitions/evals.schema.json`, `internal/config/evals.go`, `internal/core/domain/eval.go` (`EvalCaseSpec`), `internal/jonah/evals.go`, `apps/worker/src/judge.ts`; [ADR 0025](../adr/0025-judges-and-evals-as-the-screens-show-them.md) |
| Event | One recorded change of an item, run or factory, which the stream and the audit read. | `internal/core/domain/event.go` (`Event`) |
| Export | A CSV file of one list (such as runs or spend), streamed by a `GET` at the list's path plus `/export` with the same filters and permission, and capped at 100000 rows; planned, not built yet. | `internal/api` (planned); [ADR 0020](../adr/0020-saved-views-and-csv-exports.md) |
| Factory | One organization's configured production line of stations and agents, keyed by its `metadata.id` UUID and never by name. | `internal/core/domain/item.go` (`FactoryID`), `internal/factorymodel` |
| Floor | The UI screen that shows a factory's line live: its stations, their load and what needs people. | `apps/web/src/features/floor`, `apps/web/src/app/screens.ts` |
| Gate | A check at a station that sends rejected work back to an earlier station, at most a set number of times per item. | `internal/core/domain/line.go` (`Gate`), `internal/core/domain/andon.go` (`GateVerdict`) |
| Hands-off | The touchless rate: the share of a factory's finished items that no person touched, shown on the Floor. The API calls it `touchless_rate`; getTouchMetrics computes it over the range (`stats`) and for each of the last 7 days (`daily`). | [MASTER.md](../design/MASTER.md); `internal/api/touches.go` (the metrics), `internal/core/domain/touch.go` (the touches it counts) |
| Inbox | The list of an organization's open items that may need a person: waiting for a decision, blocked or expedite. | `internal/core/domain/inbox.go` (`AttentionItem`), `apps/web/src/shared/inbox.ts` |
| Item | One unit of work flowing through a factory's line, with a state at its current station. | `internal/core/domain/item.go` (`Item`, `ItemState`) |
| Jonah | Goal's planned continuous-learning loop (retros, evals and proposed changes to a definition); it is designed but not built. | [ADR 0002](../adr/0002-jonah-evals.md), [ADR 0034](../adr/0034-jonah-proposals.md), [docs/history/](../history/); the `jonah` entry in `apps/web/src/app/screens.ts` |
| Jonah review | One agent run of kind `jonah` per factory, queued by a person or after `learning.jonah.proposeAfter` new sent-back touches, that reads the sent-back reasons, the current version's files and recently rejected proposals in a box with the model connection only, and returns observations and proposals; planned, not built yet. | `internal/jonah` (planned); [ADR 0034](../adr/0034-jonah-proposals.md) |
| Judge | A Jonah definition file, `evals/judges/<slug>.md`: front matter with what it checks, the agents it scores, scored outcomes, a pass mark and a sample share, and a Markdown rubric; it scores a sample of finished production runs and never gates them. The format and its checks are built, and goal-agent's judge mode makes a judge run (one model call without tools that returns an outcome and a one-sentence reason). `domain.Judge` is a judge as goald reads it, and `internal/jonah`'s loop samples each judge's share of runs by a hash of run id and slug; no adapter reads judge files into it and goald does not start judge runs yet. | [factory-definition.md](../engineering/factory-definition.md#judges-and-eval-cases), `contracts/definitions/evals.schema.json`, `internal/config/evals.go`, `internal/core/domain/judge.go`; [ADR 0025](../adr/0025-judges-and-evals-as-the-screens-show-them.md) |
| Judge score | One judge's score of one finished production run (or of an eval case's try): queued, claimed under a lease while its judge run works, then scored (an outcome, a 0 to 1 score, passed or not, a reason and a cost) or error. A run is scored at most once per judge, and a judge's summary covers its last 30 days. The store and `internal/jonah`'s judge loop are built: it queues a score for each sampled finished run, works each under a lease (one retry after an infrastructure error) and queues tries (an item but no run, outside the 30-day figures); the loop has no adapters for its `Judges`, `FinishedRuns` and `JudgeRunner` ports and goald does not run it yet. | `internal/core/domain/judgescore.go` (`JudgeScore`, `JudgeSummary`), `internal/core/ports/judgescores.go`, `internal/jonah/jonah.go`, `internal/core/ports/jonah.go`, `internal/adapters/store/postgres/judgescores.go`, `db/migrations/00066_judge_scores.sql`; [ADR 0025](../adr/0025-judges-and-evals-as-the-screens-show-them.md) |
| Knowledge source | One source of an organization's knowledge base (uploads or a synced connection), searched by agents through the gateway. | `internal/core/domain/knowledge.go` (`KnowledgeSource`), `internal/knowledge` |
| Knowledge use | The record that a run's `knowledge__search` returned a document's chunks or its `knowledge__read` opened it, one per run, document and kind, stored in `knowledge_uses` (00072); the gateway does not record it yet. | `internal/core/domain/knowledge.go` (`KnowledgeUse`), `ports.Knowledge.RecordUse`; [ADR 0027](../adr/0027-knowledge-use-and-verdicts.md) |
| Lane | A route through a station that an earlier output chooses, so that items of one lane go to that lane's agents. | `internal/core/domain/run.go` (`LaneFrom`), `internal/core/domain/line.go` (`ErrNoRoute`) |
| Lease | An agent slot's hold on an item; it expires unless renewed, so the work of a crashed instance returns to the queue. | `internal/core/domain/run.go` (`Lease`) |
| Learned | The planned built-in knowledge source of facts learned from retros; it is not built yet. | [architecture.md](../engineering/architecture.md) ("Phases 5 and 6") |
| Line | A factory's stations in order, with its agents and flow policy, as the engine reads them. | `internal/core/domain/line.go` (`Line`) |
| Model allowlist | The models of `GOAL_MODELS` that an organization policy lets agents use, exactly one of them the default, so publishing a version that names another model is refused; planned, not built yet. | `internal/core/domain` (planned); [ADR 0024](../adr/0024-organization-policy.md) |
| Needs you | The revamp's name in the UI for the inbox, with four types: approvals, decisions, questions and alerts; the screens still say Inbox until it lands. | [MASTER.md](../design/MASTER.md); `apps/web/src/shared/inbox.ts` |
| Notification | A message to a person about an event (an approval, a question, an andon or a budget passing 80%) on the channels they turned on: In Goal, email or Slack; planned, not built yet. | `internal/core/domain` (the events, channels and preferences), `internal/core/ports` (`Mailer`), `internal/adapters/mailer/smtp`; [ADR 0023](../adr/0023-notifications-and-sign-up-by-domain.md) |
| Observation | Something a Jonah review noticed in a factory's sent-back runs: a summary, a detail line, the items it is based on and a count, shown as "Watching, n of proposeAfter" until a threshold review turns it into a proposal; planned, not built yet. | `internal/jonah` (planned); [ADR 0034](../adr/0034-jonah-proposals.md) |
| Onboarding | The steps a new person takes from signing up to a first factory: create an organization, connect code, pick a template, shape the line, set budgets, choose triggers, invite people and watch a first item; its progress is read from existing data. | `docs/design/screens/get-started/`; [ADR 0032](../adr/0032-self-serve-onboarding.md) |
| Organization | The tenant: every org-owned row carries its id and is scoped by row-level security. | `internal/core/domain/org.go` (`Org`, `OrgID`) |
| Organization policy | An organization's one set of limits over every factory (allowed models, denied commands, tool policy defaults and the box time limit), stored as a row in PostgreSQL, which a definition or an agent may narrow but never widen; planned, not built yet. | `internal/core/domain` (planned); [ADR 0024](../adr/0024-organization-policy.md) |
| Outbox | The PostgreSQL table `notification_outbox` of notifications to send, one row per event, recipient and channel, written in the event's transaction and claimed by goald's sender job with `FOR UPDATE SKIP LOCKED` and a lease; planned, not built yet. | `internal/core/ports` (the outbox port), `internal/adapters/store/postgres`, `db/migrations`; [ADR 0023](../adr/0023-notifications-and-sign-up-by-domain.md) |
| Part | One item of an assembly, counted in the assembly's progress. | `internal/core/domain/item.go` (`Part`), `internal/core/domain/part.go` |
| Personal token | A member's own token for scripts, limited to the scopes it was created with. | `internal/core/domain/personaltoken.go` (`PersonalToken`) |
| Principal | Who a request acts for, and what the database says about them at that moment. | `internal/core/domain/identity.go` (`Principal`) |
| Proposal | One hypothesis a Jonah review makes for a factory, numbered per factory ("Proposal 7"): a title, a summary, file edits (path, `base_sha256` and new content) only under `factory.yaml`, `agents/`, `skills/`, `rules/` and `contracts/`, the sent-back events it rests on and an estimate of the metric it should move, in the states proposed, published, applied, rejected and superseded; planned, not built yet. | `internal/jonah` (planned); [ADR 0034](../adr/0034-jonah-proposals.md) |
| Question | What an agent asks a person about its item (`question_asked`): `engine.Ask` ends its run (lease outcome `asked`) and leaves the item waiting for a person until `engine.Answer` records `question_answered` and puts it back in its station's queue; the item's next run reads the answer under "Answers from people". A move, pause, send-back or cancel withdraws it. The gateway's `question__ask` tool that calls `engine.Ask` is planned. | `internal/core/domain` (`Question`, `OpenQuestion`), `internal/core/engine`, `internal/gateway` (planned); [ADR 0018](../adr/0018-agents-ask-questions.md) |
| Rework | A round in which a gate sends an item back for another try. | `internal/core/domain/line.go` (`Gate.MaxRework`), `internal/core/domain/flowstats.go` (`ReworkRound`) |
| Rule | Always-on guidance a factory gives the agents, stations, lanes or work types it targets, from a `rules/<name>.md` file of the definition. | `internal/core/domain/rule.go` (`Rule`), `internal/config/rules.go` |
| Run | One agent's work on one item at one station, in its own box. | `internal/core/domain/run.go` (`Run`), `internal/core/engine` |
| Saved view | A name plus the Items page's URL search params, stored in PostgreSQL per factory, personal to its owner or shared with the factory, so that it reopens exactly that URL; planned, not built yet. | `internal/adapters/store/postgres` (planned); [ADR 0020](../adr/0020-saved-views-and-csv-exports.md) |
| Search | The shell's search box: one read that finds the items, agents, factories and connections of an organization that the caller sees, each group best first. | `internal/api/search.go` (`SearchOrg`), `Store.SearchItems` in `internal/core/ports/ports.go` |
| Skill | A folder of instructions an agent loads, from the definition or a skills.sh source. | `internal/core/domain/line.go` (`SkillRef`), `internal/core/domain/skill.go` |
| Standing rule | A person's "Always allow": one agent role may call one tool of one organization connection without asking, until someone revokes it; planned, not built yet. | `standing_rules` table and `/v1/orgs/{org}/standing-rules` (planned); [ADR 0031](../adr/0031-tool-calls-ask-first-and-standing-rules.md) |
| Starter item | The small, safe first item a template carries in `starter.item` of its definition (title, optional work type and markdown body). Onboarding submits it once, through `submitItem`, to a new factory with no items, so the person watches one item go through the line. | `starter` in `contracts/definitions/factory.schema.json`, `internal/config/starter.go` (`config.Starter`), `starter` of the factory model (`internal/factorymodel`); [factory-definition.md](../engineering/factory-definition.md#starter-item-starteritem); [ADR 0032](../adr/0032-self-serve-onboarding.md) |
| Station | One step of the line, worked by a queue, agents, people or nobody (done). | `internal/core/domain/line.go` (`Station`, `StationKind`) |
| Task token | The short-lived token a run uses to reach Goal, scoped to its organization, factory, item, station and connections. | `internal/core/domain/token.go` (`TaskClaims`) |
| Teardown | A planned after-action breakdown of one item: where its lead time, cost and human help went, station by station and run by run, with each rework loop and its cause, against the factory's target; computed on request from spans, runs, events and touches, stored nowhere. Proposed by [ADR 0019](../adr/0019-item-watch-live-trace-teardown.md) and not built yet. | `internal/core/domain/teardown.go` (`Teardown`, planned); [ADR 0019](../adr/0019-item-watch-live-trace-teardown.md) |
| Tool approval | An agent's Ask-first tool call waiting for a person (`tool_approval_requested`): its run ends and the item waits in Needs you until a person approves it, for the next run only, or denies it; planned, not built yet. | `Item.tool_approval` and the `tool_approval` inbox kind (planned); [ADR 0031](../adr/0031-tool-calls-ask-first-and-standing-rules.md) |
| Touch | One action by a person on an item, counted to show how much human help work needed. | `internal/core/domain/touch.go` (`Touch`) |
| Trace | An item's step-by-step record: each run with its tool calls and results, agent messages, checks and notes, built from item events (no full transcripts). | `apps/web/src/features/items/timeline.ts` (`buildTrace`), `trace-view.tsx` (`TraceList`); [ADR 0019](../adr/0019-item-watch-live-trace-teardown.md) |
| Trigger | A rule in `board.triggers` of a factory's definition that turns one event, schedule or webhook delivery (`on`) into a work item (`create`), after its filters, its "only if" checks (`failuresInARow`, `dedupe`) and its limits (`perDay`, `pauseOnBudget`) pass. The schema and its checks are built (`config.Trigger`); the engine that fires triggers is not yet, and `board.intake` is deprecated and ignored. | `board.triggers` in `contracts/definitions/factory.schema.json`, `internal/config/triggers.go`; [factory-definition.md](../engineering/factory-definition.md#triggers-boardtriggers); [ADR 0026](../adr/0026-intake-triggers.md) |
| Version | One saved state of a factory's definition, draft or published, with its manifest. | `internal/core/domain/definition.go` (`DefinitionVersion`) |
| Verdict | A judgment that a knowledge document helped or misled, one per actor, document and run, stored in `knowledge_verdicts` (00072); the gateway's `knowledge__verdict` tool for agents and the API and CLI for people are not built yet. | `internal/core/domain/knowledge.go` (`KnowledgeVerdict`), `ports.Knowledge.GiveVerdict`; [ADR 0027](../adr/0027-knowledge-use-and-verdicts.md) |
| Waiting | Why a waiting item is held: the open needs that hold it and the file paths that overlap. | `internal/core/domain/waiting.go` (`Waiting`) |
| Webhook endpoint | A factory's address, `POST /hooks/{endpoint id}`, that another system posts signed events to, of kind `generic` (`X-Goal-Signature`) or `github` (`X-Hub-Signature-256`), with a signing secret sealed under the master key and shown once; decided, not built yet. | PostgreSQL (planned); [ADR 0026](../adr/0026-intake-triggers.md) |
| WIP | The number of items in progress, capped per station and, for expedite items, per factory. | `internal/core/domain/line.go` (`Station.WIP`), `internal/core/domain/policy.go` (`ExpediteWIP`) |
| Work type | The kind of an item (such as a story or an outage), from the types a factory's board declares. | `internal/core/domain/item.go` (`Item.Type`), `board.workTypes` in `contracts/definitions/factory.schema.json` |
