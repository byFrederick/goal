# Change map

Keep this map accurate: every pull request that adds a new coupling between files adds or updates its row.

When you change X, also change Y, and run Z. Paths are today's; the moves of [ADR 0013](../adr/0013-repository-layout.md) update them.

| When you change | Also change | Run |
| --- | --- | --- |
| `contracts/api/openapi.yaml` | The handler in `internal/api` (never the generated `internal/api/gen`); the client in `packages/api-client` (its generated `src/schema.ts` comes from the task, routes and helpers by hand); the callers in `apps/web/`; the spec and docs that describe the endpoint | `task api:gen`, `task api:permissions-check`, `task test`, `task api-client:check`, `task web:check` |
| `contracts/api/permissions.yaml` | The operations' `x-goal-scope` in `contracts/api/openapi.yaml`; the generated table `internal/api/permissions_gen.go` and the auth roles `apps/auth/src/access.gen.ts` (both from the task); the permission tests (`internal/api/permissions_internal_test.go`, `cmd/permgen`) | `task api:gen`, `task api:permissions-check`, `task test`, `task auth:check` |
| A migration (a new file in `db/migrations/`, the next free number of the phase) | The queries in `db/queries/` and the generated `internal/adapters/postgres/db`; the `Store` port (`internal/ports/ports.go`) and its in-memory fake in `internal/ports/porttest`; the conformance suite `TestStore_Conformance`, which runs against the fake and PostgreSQL (`internal/adapters/postgres/store_integration_test.go`); row-level security for an org-scoped table; the phase's migration range in `docs/specs/README.md` | `task sqlc`, `task migrate-check`, `task test`, `task test-integration` |
| A new environment variable or platform secret | `.env.example`; `docs/engineering/cloudflare-operations.md`; for a secret, its Terraform secret and consumers in `deploy/terraform/secrets.tf`; the container environment in `deploy/cloudflare` (`wrangler.jsonc`, `src/env.ts`); reading it through the `Secrets` port (`internal/ports/ports.go`), wired in `cmd/<binary>/main.go` | `task test`, `task cloudflare:check`, `task tf:check` |
| A definition schema in `contracts/definitions/` (factory, evals, connection kind) | `contracts/definitions/schema.go`; the loader and checks in `internal/config`; `internal/connkind` and its kind files; the builder's metadata in `internal/builder`; the test fixtures in `internal/config/testdata`; the docs and spec that describe the field | `task validate`, `task test`, `task web:check` when the builder's editor shows the field |
| A Dockerfile (`cmd/goald`, `cmd/goal-egress`, `auth`, `worker`) | Its `Dockerfile.dockerignore`; its inputs in `deploy/cloudflare/scripts/images.mjs`; the app paths list of `.github/workflows/deploy.yml` | `task cloudflare:check`, the image's task (`task goald:image`, `task egress:image`, `task auth:image`, `task worker:image`) |
| Moving a directory | `Taskfile.yml` (paths, `dir:` and `sources:`); `cmd/checkplan`'s path table; the path filters and `working-directory` of `.github/workflows/ci.yml`, `deploy.yml`, `terraform-plan.yml` and `terraform-apply.yml`; Dockerfile `COPY` paths and `.dockerignore` files; `deploy/cloudflare/scripts/images.mjs`; `pnpm-workspace.yaml`; Go import paths; the `paths:` globs of `.claude/rules`; the repository map in `AGENTS.md`; the History of ADR 0013 (these three are `tools/layoutcheck`'s inputs, with the tracked files) | `task layout:check`, `task check`, `task migrate-check` when `db/migrations/` or `apps/auth/` moved |
| A new top-level directory, or a rule's `paths:` in `.claude/rules` | The repository map in `AGENTS.md` and the layout of ADR 0013 (a new top-level directory also needs the ADR's amendment, its decision 2); a glob must match at least one tracked file | `task layout:check` |
| UI under `apps/web/` | Follow `docs/design/MASTER.md` exactly and `docs/engineering/frontend.md`; the Vitest tests beside the changed components | `task web:check`, `task web:e2e` where a browser is available |
