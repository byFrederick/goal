## When you change

The spend screen under `apps/web/src/features/spend/`, its route `apps/web/src/routes/o.$org._org.spend.tsx`, its API wrapper `apps/web/src/api/spend.ts`, or the mock answer in `apps/web/mock/spend.ts`

## Also change

`docs/engineering/frontend.md` (its "Spend and billing" section and the route list) and `docs/design/screens/organization/spend.html` when the picture changes; the mock's `mock/spend.test.ts` when its answer changes; the Playwright spec `apps/web/e2e/spend.spec.ts` when a flow changes; `apps/web/src/routeTree.gen.ts` (generated by the router plugin on build) when the route moves

## Run

`pnpm --dir apps/web run typecheck`, `lint` and `test`; `task docs:check`. Playwright (`task web:e2e`) where a browser is available
