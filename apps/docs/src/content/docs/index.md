Start with [Getting started](/docs/getting-started/) to set up Goal, or read [Concepts](/docs/concepts/) to learn how a factory and its flow work.

The sections are:

- **Getting started**: install Goal and run a first item through a factory.
- **Concepts**: the factory, its flow, agents, connections, knowledge, Jonah and questions.
- **Guides**: step-by-step tasks.
- **Reference**: the CLI, the API and the factory definition.
- **Changelog**: what changed, release by release.

The [API contract](/docs/openapi.yaml) is also published as [JSON](/docs/openapi.json). Agents can read the [llms.txt index](/docs/llms.txt).
